# ARCS Field Scan

A simple interactive website for pasting a LinkedIn profile or uploading a PDF to generate an adaptive ARCS-style scan.

## Stack
- Next.js 14
- React
- TypeScript
- Tailwind CSS

## Run
```bash
npm install
npm run dev
```

## Notes
This starter currently performs a local mock scan in the browser so the UX can be reviewed immediately.
